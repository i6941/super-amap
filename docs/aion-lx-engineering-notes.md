# 超级高德 · 埃安 LX 改造笔记

本文记录截至 code159 的改动、实现思路和验证经验。安装文件与升级条件见 [GitHub Releases](https://github.com/i6941/super-amap/releases)。车型和软件版本会影响原厂接口及显示行为，以下验证范围以广汽埃安 LX 和文中所列台架为准。

## 致谢

感谢群友“我要去钓蟹”分享改造经验。本文涉及的许多修改方法，都参考了他的改动。我们在此基础上结合埃安 LX 的使用场景做了适配和验证，也把遇到的问题和排查过程整理在这里。

## 做了哪些改动

| 改动 | 实现思路 | 验证情况 |
| --- | --- | --- |
| 主屏导航和仪表飞屏 | 保留高德的地图和导航引导，主屏沿用 Android Display 0，仪表地图走独立的 Display 1。冷开机选项走高德已有的后台飞屏入口，让主屏可以继续停在桌面。 | 早期版本有 LX 实车使用记录。新版设置与自然冷开机仍需同版复测。 |
| 右桌面入口和原车语音 | 主包负责导航，独立的车机转接包把原厂桌面的导航、停车场、收藏夹、充电站和原车语音请求交给主包。保留原车高德及桌面地图 Widget。 | 转接逻辑已做离线核对。车上应分开验四个入口、语音和桌面背景。 |
| 飞屏导航卡和路口图 | 普通状态显示完整导航卡。路口图出现时，导航提示缩成一行，原生路口图显示在下方。单行提示与路口图由不同部分绘制，位置、尺寸和退场时机需要分别核对。 | Android 8.1 台架录到了单行提示和大图同屏，也录到了短暂的分阶段退场。 |
| 飞屏服务区和超速提示 | 用导航已有的服务区和测速数据绘制飞屏提示。服务区随行程进度替换。单点测速提示在台架提高模拟车速时出现，降速后消失。 | Android 8.1 台架确认服务区和单点超速效果。区间均速触发尚无运行录像。 |
| 动态续航 | 读取原厂 SOC 和 Android GPS 速度，用行程里程与净掉电估算近期续航。本机保留精简行程摘要用于估算，详细记录另有开关，便于核对动态能耗。 | GPS 和 SOC 有实车记录。估值会受工况和样本量影响。 |
| 原生「其他」设置 | 在原有设置页加入项目选项，通过应用内偏好保存开关。主屏和飞屏的动态续航分别控制。详细行程记录、冷开机飞屏、版本角标也各自有开关。 | code158 已验证设置页、角标显隐和覆盖升级后的设置保留。LX 上的新设置待逐项复核。 |
| 车辆数据调试采集 | code159 新增默认关闭的独立开关。开启后复用现有只读车辆缓存，在高德运行且缓存可用时每 30 秒最多记一条。优先保留放电和电耗候选原值，再记录 SOC、续航、充电及部分车身状态。两份轮转日志合计约 1 MiB，留在本机。 | APK 已通过 API 27 签名验证和缓存读取测试。开关和字段值待 LX 复核，候选电耗仍需确认单位和含义。 |

## 排错时值得保留的做法

1. **先确认录到了哪块屏。** 主屏录像和仪表飞屏录像分开保存，记下 Display ID、分辨率和包版本。曾有台架副屏显示普通导航页，只有真正录到副屏的路口图后，才能判断左屏缩成一行以及退场的行为。
2. **只改变一个布局变量。** 路口图放大和上移可以同时改变覆盖区域。如果开两种配置做对照，尽量固定包版本、路线、回放速度和图层条件。一次人为重叠的台架对照里，单行表头仍在前方可见。仅凭矩形有重叠，无法判定表头消失的原因。
3. **把短暂过渡与持续故障分开记录。** 分阶段退场在旧包也能看到。记录最后一帧可见和第一帧消失的时间戳，再检查后续有无持续残留。低帧率截图可能漏掉短残影。先检查位置回放是否还在推进，再判断地图或应用是否卡住。
4. **让台架测试 Android，让实车验证车辆接口。** Android 8.1 ARM64 手机适合测启动、出图、算路和双屏回放。模拟器适合复测设置、界面和安装升级。原车桌面、冷开机链路、实际车辆信号和仪表合成要在 LX 上验证。使用旧镜像时，还要记清宿主、guest ABI 和模拟器版本，避免把镜像启动故障归给高德。
5. **先保留信号原值，再确认语义。** 区分空值、接口失败、缓存时效未知和有独立对照的测量。可读字段也可能一直返回默认值。确认电耗时，把原厂显示与采样按时间对齐，再验证长度、单位和缩放比例。
6. **把升级验收拆开。** 签名、应用 ID 和版本号可以离线核对。覆盖后设置是否保留、转接是否到达、真实信号是否更新需要各自验证。车端试装前准备同签名、较高 versionCode 的恢复方案。

## 目前的研究边界

- **原生能源与补能**：已找到官方高德读取续航信息的能源界面、能耗预估和充电提醒相关代码。还需验证动态续航能否影响算路，以及充电途经点在哪里生成。
- **车道级导航**：连续车道场景已有独立的数据解析和渲染模块。LX 的启用条件和飞屏表现待运行验证。
- **仪表与真实耗电**：下一步重点是累计耗电量、平均电耗和瞬时功率。仪表软件的归属和版本仍待确认，后续可从匹配的固件定位原厂电耗页、数据入口及可离线验证的显示层。

发布包、适配条件和每版测试说明见 [GitHub Releases](https://github.com/i6941/super-amap/releases)。
